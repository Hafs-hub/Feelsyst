# Feelsyst

Plateforme d'agents IA spécialisés pour PME françaises.

## 8 agents disponibles

- 🧠 **Aria** — Stratégie & Veille marché
- ✨ **Nova** — Marketing & Contenu
- 💼 **Rex** — Prospection & Ventes
- 📊 **Vera** — Finance & Facturation
- 💬 **Lumi** — Support client
- ⚖️ **Lex** — Juridique & Conformité RGPD
- 📈 **Pulse** — Analytics & Reporting
- 🎓 **Atlas** — Onboarding & Formation

## Stack technique

- **Frontend** : HTML/CSS/JS vanilla
- **Backend** : API routes Vercel (Node.js)
- **Base de données** : Supabase (PostgreSQL)
- **IA** : Anthropic Claude (Sonnet)
- **Paiement** : Stripe
- **Emails** : Brevo
- **Déploiement** : Vercel
